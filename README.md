# Quick Lathe

Draw a half-profile of a turned part, give diameters off the spindle centerline, and get Haas SL-30 G-code. Single-file HTML app, works offline.

**Live app:** https://jimmolt.github.io/Quick-Lathe/

- OD turning and facing, ID boring, grooving, cutoff and threading (Haas canned cycles G71/G70, G72, G75, G76)
- Visible tool library and turret view with click-to-swap
- Right-click a corner point for a chamfer or radius, or a line to add a thread
- Starts from the origin (Z0 on the centerline); save and open jobs as files
